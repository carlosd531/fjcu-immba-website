# Fu Jen imMBA website

English-first redesign of the [MBA Program in International Management](https://www.management.fju.edu.tw/esubweb/immbaengindex/) at Fu Jen Catholic University.

Static HTML/CSS/JS. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 5173
```

Then visit http://localhost:5173

Content is adapted from the official College of Management pages for an international-student audience. Admissions, tuition, and partner rules should always be confirmed on the university systems linked from this site.
